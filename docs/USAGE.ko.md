# fastade 사용 가이드

*[English](USAGE.en.md)*

fastade는 Codex CLI, Claude Code, Gemini CLI 세션을 한 화면에서 실행하고 관리하는 데스크톱 터미널 클라이언트입니다. 로컬이든 SSH 원격 서버든 골라서 열면 그 서버의 홈 디렉터리에서 로그인 쉘이 시작되고, 폴더를 지정한 뒤 세션 헤더에서 원하는 AI CLI를 선택해 그 쉘 안에서 바로 실행합니다.

PTY 원본 화면을 그대로 xterm으로 보여주면서 작업 상태·메모리 사용량·사용량 통계 같은 부가 정보만 얹는 방식이라, 각 CLI의 원래 기능(슬래시 명령, 승인 요청, 대화형 UI)을 그대로 쓰면서 여러 프로젝트와 여러 세션을 한 곳에서 병행 관리할 수 있습니다.

## 단축키

| 단축키 | 동작 |
| --- | --- |
| ⌘/Ctrl + Tab (Shift 함께 역방향) | 열려 있는 세션 순환 전환 |
| ⌘/Ctrl + = (또는 +) | 터미널 글꼴 크게 |
| ⌘/Ctrl + - (또는 \_) | 터미널 글꼴 작게 |
| ⌘/Ctrl + 0 | 글꼴 크기 기본값으로 리셋 |
| Esc | 상황별로 다르게 동작: 그룹 이름 변경 취소 → 열려있는 컨텍스트 메뉴 닫기 → 설정창 닫기 → 선택된 세션에서 에이전트가 실행 중이면 중단 |

위에서 아래로, 가장 구체적인 동작부터 매칭되는 순서입니다 — 예를 들어 그룹 이름을 고치는 중에 Esc를 누르면 설정창이 아니라 변경만 취소됩니다.

## 핵심 기능

**서버 선택과 폴더 지정** — ▶를 누르면 로컬 또는 등록한 SSH 서버의 홈(`~`)에서 로그인 쉘이 열립니다. 세션 헤더의 폴더 버튼(⌂)으로 작업 폴더를 고르면 쉘이 그 폴더로 이동하고 세션 이름이 폴더 이름으로 바뀝니다.

**고정(pin)과 프로필(profile)** — 서버+폴더 조합을 고정해 두면 다음에 바로 같은 위치에서 쉘을 열 수 있습니다. 사이드바의 "Ungrouped" 섹션에서 드래그해 그룹에 배치할 수도 있습니다.

**세션 그룹** — 사이드바에서 새 그룹을 만들고 세션을 드래그 앤 드롭으로 옮겨 프로젝트별로 묶을 수 있습니다. 그룹을 삭제하면 그 안의 세션은 기본 그룹으로 이동합니다.

**AI 에이전트 실행** — 세션 헤더의 에이전트 선택에서 Codex/Claude Code/Gemini를 그 쉘 안에서 실행합니다(설정에서 지정한 CLI별 기본 model 적용). ■를 누르면 에이전트가 종료되고 쉘로 돌아갑니다.

**작업 상태 배지** — 각 세션 카드의 색상 점으로 Working(작업 중) / Needs you(승인·입력 대기) / Ready(대기 중)를 바로 확인합니다. Codex와 Claude Code는 CLI 자체 hook으로 상태를 보고받아 정확도가 높고, Gemini와 SSH 원격 세션은 터미널 출력 패턴으로 추정합니다.

**메모리·사용량 표시** — 세션 카드에 해당 쉘와 자식 프로세스의 메모리 사용량이 표시되고, 사이드바 상단의 AI USAGE 패널에서 Codex와 Claude 사용량을 주기별로 조회할 수 있습니다.

**MCP 연동** — 설정에서 토글을 켜면 해당 CLI의 설정 파일에 읽기 전용 `fastade_mcp` 항목이 추가되고, 그 에이전트가 fastade의 전체 세션 상태(list\_sessions)를 읽을 수 있게 됩니다. fastade가 만든 항목만 제거하며 기존 설정은 건드리지 않습니다. Codex는 `/hooks`에서 fastade가 추가한 hook을 신뢰해야 작업·대기 상태가 정확하게 표시됩니다.

**팝아웃·재연결** — 세션 카드의 ↗ 버튼으로 곧바로 다른 창으로 분리해 열고, 앱을 닫았다 다시 열어도 세션 이력과 메타데이터가 복원되고 종료된 세션은 ↻ 버튼으로 재연결할 수 있습니다.

## 팁과 문제 해결

- Codex의 작업·대기 상태가 부정확하거나 멈춰있다면, Codex에서 `/hooks`를 열어 fastade가 추가한 hook을 신뢰했는지 먼저 확인하세요 — 신뢰하지 않으면 터미널 텍스트 추정으로만 상태를 판단해 정확도가 떨어집니다.
- Gemini CLI와 SSH 원격 세션은 hook 연동이 없어 터미널 출력만으로 상태를 추정합니다. 화면에 남아있는 문구 때문에 상태가 실제와 다르게 표시될 수 있으니 참고하세요.
- SSH 비밀번호는 OS 보안 저장소(keychain)에만 저장되며 프로파일 JSON에는 남지 않습니다.
- MCP 브리지의 로컬 IPC는 현재 macOS와 Linux에서만 동작하며, Windows는 아직 지원되지 않습니다.
- 브라우저 단독 실행은 지원되지 않습니다 — 프론트엔드가 Tauri IPC로 Rust host와 통신하므로 `npm run tauri:dev`(또는 빌드된 앱)로만 실행해야 합니다.
